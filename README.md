# PocketCass Website

Static marketing, support, and privacy website for PocketCass.

## GitHub Pages

The complete publishable site is made from these files:

- `index.html` — marketing page
- `support.html` — technical support
- `privacy.html` — privacy policy
- `styles.css` — shared styles
- `site.js` — localization and page rendering
- `assets/` — the icon, paper texture, and display font

All links are relative. The site works on GitHub Pages without dependencies or a build step.
